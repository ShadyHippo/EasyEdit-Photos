Mobile options — 3 directions

Same phone, same dark theme, same tools. The only thing that changes is where the options live and how you reach them. Tap the tools in any frame — each one is live. The bottom row is the tool dock; the options for the active tool are highlighted with a numbered ● badge.

Direction A · Options rail

A thin strip pinned above the dock, always visible, that swaps to the active tool's controls. Nothing is modal, so the canvas never gets covered — you watch the stroke change as you drag.

  • ●1 Options are always on screen — no tap to reveal.
  • ●2 Canvas stays fully visible while you adjust.
  • ●3 "More" opens the full sheet (layers, effects, resize, export).

Direction B · Swap mode

The bottom bar has two states. Normally it's the tool picker; pick a tool and it becomes that tool's options. "‹ Tools" goes back. One row of chrome, so the canvas gets the most room.

  • ●1 Picking a tool swaps the bar to its options (auto-reveal).
  • ●2 "‹ Tools" returns to the picker.
  • ●3 "More" opens the full sheet.

Direction C · Smart sheet

Keep the familiar sheet, but make it behave: it auto-opens on the matching tab when you pick a tool, is capped short so the canvas peeks above, has a grabber to swipe away, and the opener moves into the dock.

  • ●1 Opener now lives in the dock (thumb reach), not the top bar.
  • ●2 Sheet auto-opens on tool pick; canvas stays visible above.
  • ●3 Grabber + swipe-down (or backdrop tap) to dismiss.
